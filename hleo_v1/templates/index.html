Setup steps to connect Reddit:

  1. Go to reddit.com/prefs/apps
  2. Click Create another app… → choose script
  3. Name it anything; set redirect URI to http://localhost
  4. Copy the client ID (under the app name) and the secret
  5. Add them as Replit Secrets: REDDIT_CLIENT_ID and REDDIT_CLIENT_SECRET
